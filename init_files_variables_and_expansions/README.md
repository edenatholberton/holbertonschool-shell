README.md file for the subdirectory: init_files_variables_and_expansions. Will list what was done for each task of the project.

- 1-hello_you: Adding a script that prints "hello user". This was done through a parameter expansion.
- 2-path: Added a script that adds /action to the PATH. /action has to be the last directory the shell looks into when looking for a program.
- 3-paths: Added script that counts the number of directories in the PATH. Used variables, expansions and filter commands.
- 4-global_variables: Created a script that lists environment variables.
- 5-local_variables: Created a script that lists all local variables and environment variables, and functions. This was displayed with the 'set' command.
- 6-create_local_variable: Created a script that creates a new local variable.
- 7-create_global_variable: Created a script that creates a new global variable - this is referred to as Exporting [a] variable.
- 8-true_knowledge: Wrote a script that prints the result of the addition of 128 with tehvalue stored in the environemtn variable 'TRUEKNOWLEDGE', follow by a new line. - Arithmetic expansion.
- 9-divide_and_rule: Wrote a script that prints the results, from a division arithmetic expansion. "POWER" and "DIVIDE" being environment variables.
- 10-love_exponent_breath: Wrote a script that prints two variables from the power of using arithmetic expansion. (**)
- 11-binary_to_decimal: Wrote a script that converts a number from base 2 to base 10. + the number in base 2 was stored in the environment variable 'BINARY'
- 12-combinations: Wrote a script that prints all the possible combinations of two letters except "oo". echo for the print, tr for the new line ('\n'), and grep to remove the oo were all used.
- 13-print_float: Wrote a script that prints a number with two decimal places, followed by a new line. printf, %, .2, f, \n, $num were all used.
- 14-decimal_to_hexadecimal: Wrote a script that converts a number from base 10 to base 16. The base 10 variable was "DECIMAL". found in the man printf section.
