This is a README file for everything inside the "io_redirections_and_filters" folder.

- 0-hello_world:  Wrote a script that prints "Hello, World" when ran.
- 1-confused_smiley: Wrote a script that prints a confused smiley face "(Ôo)'. But for me to get the "Ô" to appear, I had to write this command "export LANG=C.UTF-8" in the shell, which made it work.
- 2-hellofile: Wrote a script that prints how to display the contents inside a file.
- 3-twofiles: Wrote a script that prints how to display contents of two different files at the same time.
- 4-lastlines: Wrote a script that produces the last 10 lines of a file - using the TAIL command.
- 5-firstlines: Wrote a script that produces the first 10 lines of a file - using the HEAD command.
- 6-third_line: Wrote a script that prints how to display a specific line of code. First use of the pipe (|) tool as well.
- 7-file: Wrote a script that creates a file named exactly `\*\\'"Best School"\'\\*$\?\*\*\*\*\*:)` containing the text Best School ending by a new line. This was done by adding a backslash to every ",\,$" which was 15 in total. Echo, and redirect were also used.
- 8-cwd_state: Wrote a script that writes the results of "ls -la" into a specific file.
- 9-duplicate_last_line: Wrote a script that duplicates the last line from a file to a file.
- 10-no_more_js: Wrote a script that deletes all regular files ending in ".js", in the current directory and subdirectories.
- 11-directories: Wrote a script that counts the number of directories and sub-directories. But this time, the current and parents directories should not be included in the count. The command -mindepth was used, and a pipe "|".
- 12-newest_files: Wrote a script that displays the 10 newest files in the current directory. With the rules of one file per line and sorted from newest to oldest. "-t" was used here.
