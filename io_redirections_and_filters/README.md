This is a README file for everything inside the "io_redirections_and_filters" folder.

- 0-hello_world:  Wrote a script that prints "Hello, World" when ran.
- 1-confused_smiley: Wrote a script that prints a confused smiley face "(Ôo)'. But for me to get the "Ô" to appear, I had to write this command "export LANG=C.UTF-8" in the shell, which made it work.
- 2-hellofile: Wrote a script that prints how to display the contents inside a file.
- 3-twofiles: Wrote a script that prints how to display contents of two different files at the same time.
