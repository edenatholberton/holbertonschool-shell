- 0-iam_betty: Script prints how to change current user to the user 'betty'
- 1-who_am_i: Script that prints the effective username of the current user.
- 2-groups: Script that prints all the groups the current user is a part of.
- 3-new_owner: Did two things, A: created a /tmp file that writes a script that changes the owner of the file 'hello' to the user 'betty'. This meant I had to create a new user through the 'adduser betty' command. I then wrote the same script in the permissions directory.
- 4-empty: Wrote a script that creates a new empty file (called hello)
- 5-execute: Added a script that adds the execute permission to the owner of the file "hello".
- 6-multiple_permissions: Added a script that adds execute permission to the owner and the group owner, and read permission to other users, to the file "hello".
- 7-everybody: Wrote a script that changes the execute permissions for everybody.
- 8-James_Bond: Wrote a script that sets permissions to a file with the owner and group having no permissions but others having them all. To get the answer for the script, I had to conver the rwx into binary to get a value.
- 9-John_Doe: Wrote a script using numeric mode that set the permissions of the file "hello".
- 10-mirror_permissions: Wrote a script using chmod --reference, which allowed me to copy one permission mode from a file to another.
- 11-directories_permissions: Wrote a script that adds execute permission to all subdirectories of the current directory for the owner, the group owner and all other users. Regular files were not be changed.
- 12-directory_permissions: Wrote a script that creates a directory called my_dir with permissions 751 in the working directory.
- 13-change_group: Wrote a script that changes the group owner to school for the file hello
- 14-change_owner_and_group: Wrote a script that changes the owner to vincent and the group owner to staff for all the files and directories in the working directory.
- 15-symbolic_link_permissions: Write a script that changes the owner and the group owner of _hello to vincent and staff respectively. The file _hello is in the working directory and is a symbolic link, so I used 'man chown' and searched for dereference.
